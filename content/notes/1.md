오늘은 캡스톤 프로젝트를 진행하면서 필요한 내용들을 정리하고, React와 Git/GitHub를 공부했다.

## React

캡스톤에서 맡은 프론트엔드 역할을 준비하기 위해 React에서 필요한 부분들을 학습했다.

- 컴포넌트와 상태 관리 개념 복습
- 사용자 입력값을 상태로 관리하는 흐름 정리
- 체크리스트처럼 상태에 따라 UI가 변경되는 방식 학습
- Context API, Zustand, Recoil 등 상태 관리 방식 확인
- React Hook Form을 이용한 입력 폼 관리 개념 확인
- axios / fetch를 이용한 API 통신 흐름 학습
- React Query, SWR과 같은 서버 상태 관리 방식 확인
- 조건부 렌더링과 진행률 UI 구현 방식 정리

아직 모든 기능을 직접 구현한 것은 아니지만,
캡스톤에서 내가 맡은 사용자 입력과 체크리스트 화면을 만들기 위해 어떤 React 기능을 공부해야 하는지 정리했다.

## Capstone Project

캡스톤 프로젝트 **'챙김'** 관련 보고서를 작성하고 기존 내용을 정리했다.

오늘 정리한 내용은 크게 다음과 같다.

- 서비스 개요와 주요 기능 정리
- 유사 서비스 조사 및 비교
- 사용자 입력 기능 정리
- 생성된 체크리스트를 화면에 표시하는 기능 정리
- 체크리스트 완료 여부 관리
- 전체 진행률 표시 기능 정리

내가 맡은 프론트엔드 부분은 사용자가 자신의 상황을 자연어로 입력할 수 있는 화면과,
생성된 체크리스트를 확인하고 관리할 수 있는 UI를 구현하는 것이다.

전체 흐름도 다시 정리했다.

**사용자 입력 → 자연어에서 조건 추출 → 조건을 기반으로 체크리스트 생성 → 화면에 체크리스트 표시**

- 사이트 기본 정보 변경
