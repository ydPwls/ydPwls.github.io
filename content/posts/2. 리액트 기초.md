## 1. React 기초

### React란?

React는 사용자 인터페이스(UI)를 만들기 위한 JavaScript 라이브러리임.

기존 HTML에서는 하나의 페이지를 작성할 때 화면 전체를 구성하지만, React에서는 화면을 여러 개의 **컴포넌트(Component)** 로 나누어 개발함.

각각의 컴포넌트를 따로 만들기 때문에 코드 관리와 재사용이 편리함.

### 컴포넌트 (Component)

컴포넌트는 React 화면을 구성하는 독립적인 UI 단위임.

**큰 화면 → 여러 컴포넌트로 분리 → 각 컴포넌트를 조합해서 하나의 화면 구성**

### JSX

JSX는 JavaScript 코드 안에서 HTML과 비슷한 문법을 작성할 수 있도록 하는 문법임.

React에서는 JSX를 이용해서 JavaScript 데이터와 UI를 연결할 수 있음.

### Props

Props는 부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하는 방법임.

### State

State는 컴포넌트에서 변경될 수 있는 데이터임.

Props가 부모에게서 전달받은 데이터라면, State는 **컴포넌트의 현재 상태를 나타내는 데이터**임.

챙김 체크리스트로 예를 들면 다음과 같은 값들이 상태가 될 수 있음.

- 미완료 → 완료
- 진행률 30% → 40%
- 팝업 닫힘 → 열림
- 현재 질문 1번 → 2번

### useState

`useState`는 React에서 상태를 만들고 관리할 때 사용하는 Hook임.

Hook은 쉽게 말하면 React의 여러 기능을 함수 컴포넌트에서 사용할 수 있도록 해주는 기능임.

```jsx
const [completed, setCompleted] = useState(false);
```

각각의 의미는 다음과 같음.

- `completed` → 현재 상태값
- `setCompleted` → 상태를 변경하는 함수
- `false` → 상태의 초기값

따라서 처음에는 `completed = false`이고,

```jsx
setCompleted(true);
```

를 실행하면 `completed = true`로 변경됨.

### 이벤트 처리

React에서는 사용자의 클릭이나 입력 같은 행동을 **이벤트(Event)** 로 처리함.

예를 들어 버튼을 클릭했을 때 상태를 변경하도록 작성했다면 다음 순서로 동작함.

**사용자 버튼 클릭 → `onClick` 실행 → `setCompleted(true)` → State 변경**

### 렌더링과 리렌더링

렌더링(Rendering)은 React가 컴포넌트의 내용을 화면에 표시하는 과정임.

State가 변경되면 React는 변경된 내용을 화면에 반영하기 위해 컴포넌트를 다시 렌더링함. 이를 **리렌더링(Re-rendering)** 이라고 함.

예를 들면 다음과 같음.

**`completed = false` → "미완료" 표시**

사용자가 버튼을 클릭하면:

**사용자 클릭 → `setCompleted(true)` → State 변경 → React 리렌더링 → "완료" 표시**
