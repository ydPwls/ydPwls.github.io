# React 폼 상태 관리

## 1. 폼 상태 관리

### 폼(Form)이란

폼은 사용자가 데이터를 입력하거나 선택할 수 있도록 만들어진 UI이다.

예를 들어 다음과 같은 것들이 모두 폼에 해당한다.

- 이름 입력
- 지역 선택
- 날짜 선택
- 이벤트 유형 선택
- 질문에 대한 답변 입력

챙김의 대화형 상황 입력에서도 사용자가 여러 질문에 답변하고 선택한 값을 저장해야 하기 때문에 폼 상태 관리가 필요하다.

### 폼 상태 관리란

예를 들어 챙김에서 이사 상황에 대한 질문을 진행한다면 다음과 같은 여러 입력값이 만들어질 수 있다.

```text
이벤트 = 이사
지역 = 경산
예정일 = 10월 20일
주거 형태 = 월세
첫 독립 여부 = true
```

단순한 입력값은 `useState`를 사용해서 관리할 수 있다.

```jsx
const [region, setRegion] = useState("");
```

사용자가 값을 입력하면 다음과 같은 흐름으로 동작한다.

```text
사용자 입력
    ↓
onChange 이벤트 발생
    ↓
setRegion()
    ↓
State 변경
    ↓
화면에 변경된 값 반영
```

### useState만 사용했을 때의 문제

입력 항목이 적다면 `useState`만 사용해도 충분하다.

하지만 질문이 많아지면 각각의 입력값에 State를 만들어야 한다. 또한 각 입력마다 `onChange` 처리와 유효성 검사를 작성해야 하기 때문에 폼의 규모가 커질수록 코드가 복잡해질 수 있다.

이러한 폼 데이터를 더 편리하게 관리하기 위해 **React Hook Form**과 같은 라이브러리를 사용할 수 있다.

## 2. React Hook Form

### React Hook Form이란

React Hook Form은 React에서 폼의 입력값과 유효성 검사를 관리할 수 있도록 도와주는 라이브러리이다.

여러 입력값을 각각 `useState`로 관리하는 대신 입력 요소를 React Hook Form에 등록하여 폼 데이터를 관리할 수 있다.

입력값 등록(`register`), 검증, 상태 추적(`watch`), 제출 처리(`handleSubmit`) 등의 기능을 제공한다.

설치 방법은 다음과 같다.

```bash
npm install react-hook-form
```

### useForm

`useForm`은 React Hook Form에서 폼을 관리하기 위해 사용하는 Hook이다.

```jsx
const { register, handleSubmit } = useForm();
```

대표적으로 다음과 같은 기능을 사용할 수 있다.

- `register` : 입력 요소를 React Hook Form에 등록
- `handleSubmit` : 폼 제출 처리
- `formState` : 폼의 현재 상태 관리
- `errors` : 유효성 검사에서 발생한 오류 관리

> `errors`는 일반적으로 `formState`에서 구조 분해하여 가져온다.

```jsx
const {
  register,
  handleSubmit,
  formState: { errors },
} = useForm();
```

### register

`register`는 `input`과 같은 입력 요소를 React Hook Form에 등록하는 기능이다.

```jsx
<input {...register("region")} />
```

위 코드에서는 해당 입력값을 `region`이라는 이름으로 관리한다.

사용자가 `경산`을 입력하면 폼 데이터는 다음과 같이 만들어질 수 있다.

```js
{
  region: "경산"
}
```

여러 입력값을 등록할 수도 있다.

```jsx
<input {...register("region")} />
<input {...register("date")} />
<input {...register("housingType")} />
```

그러면 다음과 같이 하나의 폼 데이터로 관리할 수 있다.

```js
{
  region: "경산",
  date: "2026-10-20",
  housingType: "월세"
}
```

### handleSubmit

`handleSubmit`은 사용자가 폼을 제출했을 때 입력값을 확인하고 제출 함수를 실행하는 기능이다.

```jsx
const onSubmit = (data) => {
  console.log(data);
};

<form onSubmit={handleSubmit(onSubmit)}>
```

동작 과정은 다음과 같다.

```text
사용자가 제출 버튼 클릭
        ↓
handleSubmit 실행
        ↓
입력값 및 유효성 검사
        ↓
문제가 없으면 onSubmit 실행
        ↓
입력된 폼 데이터 전달
```

### 유효성 검사

유효성 검사는 사용자가 입력한 값이 조건에 맞는지 확인하는 과정이다.

예를 들어 지역을 반드시 입력하도록 설정할 수 있다.

```jsx
<input
  {...register("region", {
    required: "지역을 입력해주세요.",
  })}
/>
```

입력하지 않은 상태에서 제출하면 오류를 표시할 수 있다.

```jsx
{errors.region && <p>{errors.region.message}</p>}
```

챙김의 대화형 질문에서는 현재 질문에 대한 답변이 입력되었는지 확인한 뒤 다음 질문으로 이동하는 방식으로 활용할 수 있다.

```text
현재 질문 표시
      ↓
사용자 답변 입력
      ↓
유효성 검사
   ↙      ↘
 실패      성공
  ↓          ↓
오류 표시   다음 질문으로 이동
```

## 3. 챙김에서의 활용

챙김에서는 이벤트 유형에 따라 여러 질문에 대한 답변을 입력받아야 한다.

React Hook Form을 사용하면 이러한 입력값과 유효성 검사를 하나의 폼으로 관리할 수 있다.

각 상태 관리 방식의 역할을 구분하면 다음과 같다.

```text
단순 UI 상태
→ useState

여러 사용자 입력값과 유효성 검사
→ React Hook Form

여러 컴포넌트에서 공유해야 하는 상태
→ Zustand
```

즉, 모든 상태를 하나의 방식으로 관리하기보다는 상태의 역할에 따라 `useState`, React Hook Form, Zustand를 구분하여 사용할 수 있다.
