# REST API 연동 기초

## 1. REST API

### API란

API는 서로 다른 프로그램이 데이터를 주고받을 수 있도록 정해놓은 방법이다.

React로 만든 프론트엔드에서 서버의 데이터를 사용하려면 API를 통해 서버에 요청을 보내고 응답을 받아야 한다.

예를 들어 챙김에서 체크리스트를 불러온다면 다음과 같은 과정으로 데이터를 주고받을 수 있다.

```text
React 프론트엔드
      ↓
체크리스트 요청
      ↓
API
      ↓
서버
      ↓
데이터 조회
      ↓
API 응답
      ↓
React 화면에 체크리스트 표시
```

### REST API란

REST API는 HTTP를 이용해 데이터를 요청하고 처리하는 API 방식 중 하나이다.

일반적으로 HTTP Method를 사용하여 어떤 작업을 할 것인지 구분한다.

| Method | 역할 | 챙김에서의 예시 |
| --- | --- | --- |
| GET | 데이터 조회 | 체크리스트 조회 |
| POST | 데이터 생성 또는 전송 | 사용자 상황 입력 결과 저장 |
| PUT | 데이터 전체 수정 | 저장된 사용자 정보 전체 수정 |
| PATCH | 데이터 일부 수정 | 체크리스트 완료 상태 변경 |
| DELETE | 데이터 삭제 | 저장된 체크리스트 삭제 |

## 2. fetch를 이용한 API 연동

### fetch란

`fetch`는 브라우저에서 기본으로 제공하는 HTTP 요청 기능이다.

별도의 라이브러리를 설치하지 않고 서버에 API 요청을 보낼 수 있다.

GET 요청은 다음과 같이 작성할 수 있다.

```jsx
const response = await fetch("/api/checklists");
const data = await response.json();

console.log(data);
```

각 코드의 역할은 다음과 같다.

```text
fetch()
→ 서버에 HTTP 요청

response
→ 서버에서 전달받은 응답

response.json()
→ 응답 데이터를 JavaScript에서 사용할 수 있도록 변환

data
→ 실제 사용할 데이터
```

### POST 요청

서버에 데이터를 전달할 때는 다음과 같이 사용할 수 있다.

```jsx
await fetch("/api/answers", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    eventType: "이사",
    region: "경산",
  }),
});
```

`method`를 통해 POST 요청임을 지정하고 `body`에 서버로 전달할 데이터를 넣는다.

이때 JSON 데이터를 전송하기 위해 `Content-Type`을 `application/json`으로 지정하고 `JSON.stringify()`를 이용해 데이터를 JSON 문자열로 변환한다.

## 3. axios를 이용한 API 연동

### axios란

`axios`는 HTTP 요청을 편리하게 처리할 수 있도록 만들어진 JavaScript 라이브러리이다.

`fetch`와 마찬가지로 GET, POST, PATCH, DELETE 등의 HTTP 요청을 보낼 수 있다.

React의 기본 기능은 아니기 때문에 별도의 설치가 필요하다.

```bash
npm install axios
```

### GET 요청

```jsx
const response = await axios.get("/api/checklists");

console.log(response.data);
```

axios에서는 서버에서 받은 데이터를 `response.data`를 통해 사용할 수 있다.

### POST 요청

```jsx
await axios.post("/api/answers", {
  eventType: "이사",
  region: "경산",
});
```

`fetch`와 비교하면 요청 데이터를 직접 JSON 문자열로 변환하거나 기본적인 JSON 요청 설정을 작성하지 않아도 되기 때문에 비교적 간단하게 사용할 수 있다.

### fetch와 axios 비교

| 구분 | fetch | axios |
| --- | --- | --- |
| 종류 | 브라우저 기본 기능 | 외부 라이브러리 |
| 별도 설치 | 필요 없음 | 필요함 |
| JSON 응답 처리 | 직접 `response.json()` 호출 | `response.data` 사용 |
| POST 데이터 처리 | JSON 변환 등을 직접 설정 | 비교적 간단함 |
| HTTP 오류 처리 | 응답 상태를 직접 확인해야 함 | 일반적인 HTTP 오류를 자동으로 오류 처리 |
| 공통 API 설정 | 직접 구성 | 비교적 편리함 |

## 4. 비동기 처리

### 비동기 처리란

API 요청을 보내면 서버의 응답이 즉시 도착하는 것이 아니라 요청을 처리하는 시간이 필요하다.

예를 들어 다음과 같은 과정이 이루어진다.

```text
React
  ↓
API 요청
  ↓
서버에서 요청 처리
  ↓
데이터 조회
  ↓
서버 응답
  ↓
React에서 결과 처리
```

이처럼 결과가 바로 만들어지지 않는 작업을 처리하기 위해 비동기 처리가 필요하다.

### async / await

JavaScript에서는 비동기 작업을 처리할 때 `async`와 `await`를 사용할 수 있다.

`async`는 함수 안에서 `await`를 사용할 수 있도록 하며, `await`는 Promise의 처리가 완료될 때까지 해당 함수의 다음 코드 실행을 기다리게 한다.

```jsx
const loadChecklists = async () => {
  const response = await axios.get("/api/checklists");

  console.log(response.data);
};
```

동작 과정은 다음과 같다.

```text
loadChecklists 실행
      ↓
axios.get() 실행
      ↓
서버에 요청
      ↓
응답 대기
      ↓
서버 응답
      ↓
response에 결과 저장
      ↓
다음 코드 실행
```

### 오류 처리

서버 요청은 네트워크 문제나 서버 오류 등으로 실패할 수 있다.

`try / catch`를 사용하면 정상적인 처리와 오류 처리를 구분할 수 있다.

```jsx
const loadChecklists = async () => {
  try {
    const response = await axios.get("/api/checklists");

    console.log(response.data);
  } catch (error) {
    console.error(error);
  }
};
```

`try` 내부에서는 API 요청을 실행하고, 요청 과정에서 오류가 발생하면 `catch`가 실행된다.

## 5. API 요청과 State

서버에서 가져온 데이터는 React State에 저장하여 화면에서 사용할 수 있다.

```jsx
const [checklists, setChecklists] = useState([]);

const loadChecklists = async () => {
  const response = await axios.get("/api/checklists");

  setChecklists(response.data);
};
```

전체적인 흐름은 다음과 같다.

```text
API 요청
   ↓
서버 응답
   ↓
데이터 전달
   ↓
setChecklists()
   ↓
State 변경
   ↓
React 리렌더링
   ↓
화면에 데이터 표시
```

즉, 서버에서 데이터를 받아 State를 변경하면 React가 변경된 State를 기준으로 화면을 다시 렌더링한다.

## 6. Loading과 Error 상태

API 요청은 서버의 응답을 기다리는 시간이 있기 때문에 사용자에게 현재 상태를 알려주는 것이 필요하다.

대표적으로 다음과 같은 상태가 있다.

```text
Loading
→ 데이터를 불러오는 중

Success
→ 데이터를 정상적으로 불러옴

Error
→ 데이터를 불러오는 과정에서 오류 발생
```

`useState`를 이용하면 다음과 같이 관리할 수 있다.

```jsx
const [loading, setLoading] = useState(false);
const [error, setError] = useState(null);
```

API 요청을 시작할 때는 다음과 같이 변경한다.

```jsx
setLoading(true);
```

요청이 끝나면 다시 `false`로 변경한다.

```jsx
setLoading(false);
```

실제로는 `try / catch / finally`와 함께 사용할 수 있다.

```jsx
const loadChecklists = async () => {
  try {
    setLoading(true);
    setError(null);

    const response = await axios.get("/api/checklists");

    setChecklists(response.data);
  } catch (error) {
    setError(error);
  } finally {
    setLoading(false);
  }
};
```

동작 과정은 다음과 같다.

```text
API 요청 시작
      ↓
loading = true
      ↓
"불러오는 중..." 표시
      ↓
서버 응답
   ↙       ↘
 성공       실패
  ↓          ↓
데이터 저장  error 저장
   ↘        ↙
loading = false
      ↓
화면 업데이트
```

## 7. useEffect를 이용한 API 요청

### useEffect란

`useEffect`는 React 컴포넌트가 렌더링된 이후 특정 작업을 실행하기 위해 사용하는 Hook이다.

예를 들어 체크리스트 화면에 들어왔을 때 서버에서 데이터를 자동으로 가져와야 한다면 `useEffect`를 사용할 수 있다.

```jsx
useEffect(() => {
  loadChecklists();
}, []);
```

빈 의존성 배열 `[]`을 사용하면 컴포넌트가 마운트된 이후 Effect가 실행된다.

### API 요청과 연결

```text
체크리스트 화면 표시
      ↓
useEffect 실행
      ↓
loadChecklists()
      ↓
axios GET 요청
      ↓
서버 응답
      ↓
setChecklists()
      ↓
State 변경
      ↓
React 리렌더링
      ↓
체크리스트 화면 표시
```

이를 통해 사용자가 별도의 동작을 하지 않아도 화면에 필요한 데이터를 서버에서 가져올 수 있다.

## 8. React Query

`useEffect`와 `useState`를 이용해서 서버 데이터를 직접 관리할 수도 있지만, API 요청이 많아지면 로딩, 오류, 데이터 갱신 등을 직접 관리해야 한다.

React Query는 이러한 **서버 상태를 관리하기 위한 라이브러리**이다.

대표적으로 다음과 같은 기능을 제공한다.

- 서버 데이터 조회
- 로딩 및 오류 상태 관리
- 데이터 캐싱
- 데이터 다시 가져오기
- 서버 데이터 갱신 관리

### 캐싱

캐싱은 서버에서 가져온 데이터를 저장해두었다가 다시 활용하는 방식이다.

```text
서버에서 데이터 조회
      ↓
React Query가 데이터 캐싱
      ↓
같은 데이터가 다시 필요
      ↓
캐시된 데이터 활용
```

따라서 서버 상태를 직접 관리하는 코드를 줄이고 데이터를 효율적으로 관리할 수 있다.

SWR도 React Query와 비슷하게 서버 데이터 조회와 캐싱을 지원하는 라이브러리이다.

두 라이브러리는 비슷한 역할을 하기 때문에 일반적으로 하나를 선택하여 사용한다.

## 9. 챙김에서의 활용

챙김에서는 사용자가 입력한 상황을 서버에 전달하고 서버에서 처리된 체크리스트나 정책 등의 데이터를 다시 받아와야 한다.

```text
사용자 상황 입력
      ↓
axios
      ↓
REST API
      ↓
서버에서 데이터 처리
      ↓
응답 반환
      ↓
React에서 결과 표시
```

기본적인 API 요청은 `axios`와 `async / await`를 이용해 처리할 수 있다.

화면이 나타났을 때 자동으로 데이터를 가져와야 하는 경우에는 `useEffect`를 이용할 수 있다.

이후 서버에서 관리하는 데이터와 API 요청이 많아질 경우 React Query를 이용하여 서버 상태와 캐싱을 관리하는 방향을 고려할 수 있다.
